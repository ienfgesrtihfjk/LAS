1. Quick Start
Paste this into your executor and run it:
lualocal LumoAdmin = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/YOUR_USER/YOUR_REPO/main/LumoAdmin.lua"
))()
Once loaded you will see a Success notification. Press ; (semicolon) or Insert to open the command bar.

2. Loading via Executor / loadstring
LumoAdmin.lua is a module that returns its API table. When you loadstring it, assign the return value:
lua-- Basic load
local LumoAdmin = loadstring(game:HttpGet("RAW_URL"))()

-- Now you have full access to the API:
LumoAdmin.AddCommand(...)
LumoAdmin.Notify(...)
LumoAdmin.CreateWindow(...)

Note: game:HttpGet requires the executor to have HTTP request permissions.

Re-execution safety
The script removes any pre-existing LumoAdmin ScreenGui before creating a fresh one, so you can re-run it without getting duplicate UIs.

5. Adding Custom Commands
Basic signature
luaLumoAdmin.AddCommand(name, definition)
ParameterTypeDescriptionnamestringPrimary command name (used for lookup and autocomplete)definition.DescriptionstringShort description shown in cmds listdefinition.Aliasestable<string>Alternative names the user can typedefinition.UsagestringUsage hint shown in cmds list (e.g. "ws <speed>")definition.Executefunction(args)Called when command runs; args is a table of string tokens
Minimal example
luaLumoAdmin.AddCommand("hello", {
    Description = "Says hello in a notification",
    Execute = function(args)
        LumoAdmin.Notify({
            Title   = "Hello!",
            Message = "Hi there, " .. (args[1] or "world") .. "!",
            Type    = "Success",
        })
    end,
})
Run it: > hello Claude
Full example with aliases and usage
luaLumoAdmin.AddCommand("heal", {
    Description = "Set your character health",
    Aliases     = { "health", "hp" },
    Usage       = "heal [amount]",
    Execute     = function(args)
        local char = game.Players.LocalPlayer.Character
        local hum  = char and char:FindFirstChildOfClass("Humanoid")
        if not hum then
            LumoAdmin.Notify({ Title = "Heal", Message = "No humanoid found.", Type = "Error" })
            return
        end
        local amount = tonumber(args[1]) or hum.MaxHealth
        hum.Health = math.min(amount, hum.MaxHealth)
        LumoAdmin.Notify({
            Title   = "Heal",
            Message = string.format("Health set to %.0f / %.0f", hum.Health, hum.MaxHealth),
            Type    = "Success",
        })
    end,
})
Overwriting a built-in command
Simply call AddCommand with the same name — it replaces the existing entry:
luaLumoAdmin.AddCommand("fly", {
    Description = "My custom fly with fixed speed",
    Execute = function(args)
        -- custom implementation
    end,
})
Removing a command
luaLumoAdmin.Commands["commandname"] = nil

8. MakeDraggable
luaLumoAdmin.MakeDraggable(frame, handle)
Makes frame draggable. handle is the part the user clicks to drag (defaults to frame itself). Pass the title bar of a custom window as handle.
lualocal myFrame = Instance.new("Frame")
-- ... setup ...
LumoAdmin.MakeDraggable(myFrame, myFrame) -- drag anywhere on the frame

-- Or with a dedicated handle:
LumoAdmin.MakeDraggable(myFrame, titleBarFrame)

10. Framework Architecture
LumoAdmin (table / module)
├── _VERSION         string
├── _NAME            string
├── Commands         { [name]: CommandDefinition }
├── Settings         { OpenKey, AltOpenKey, … }
│
├── AddCommand(name, def)       Register a command
├── Notify(options)             Fire a notification
├── CreateWindow(options)       Create a draggable UI window
└── MakeDraggable(frame, handle)

Internal (not part of public API, but readable):
├── CommandBar GUI              (Bar, BarInput, ACFrame)
├── NotifHolder                 ScrollingFrame that holds toasts
├── OpenBar() / CloseBar()      Bar animation
└── RunCommand(rawString)       Parser + dispatcher
How command resolution works

User types > ws 80 and presses Enter
RunCommand("ws 80") is called
Input is tokenised → cmdKey = "ws", args = {"80"}
Commands table is scanned:

Exact match on key name
Then alias scan for each command


found.Execute({"80"}) is called inside pcall
If pcall errors, an Error notification is shown automatically

Autocomplete resolution
Autocomplete only triggers while the user is typing the first word (no space yet). It does prefix matching against all command names and their aliases.

11. Full Custom Command Examples
Example A — Infinite jump toggle
lualocal ijConn = nil
local ijActive = false

LumoAdmin.AddCommand("ijump", {
    Description = "Toggle infinite jump",
    Aliases     = { "infinitejump", "ij" },
    Usage       = "ijump",
    Execute     = function()
        local lp = game.Players.LocalPlayer
        if ijActive then
            ijActive = false
            if ijConn then ijConn:Disconnect() ijConn = nil end
            LumoAdmin.Notify({ Title = "Infinite Jump", Message = "Disabled.", Type = "Info" })
        else
            ijActive = true
            ijConn = game:GetService("UserInputService").JumpRequest:Connect(function()
                local char = lp.Character
                local hum  = char and char:FindFirstChildOfClass("Humanoid")
                if hum then hum:ChangeState(Enum.HumanoidStateType.Jumping) end
            end)
            LumoAdmin.Notify({ Title = "Infinite Jump", Message = "Enabled.", Type = "Success" })
        end
    end,
})

Example C — Command with a confirmation step
luaLumoAdmin.AddCommand("clearworkspace", {
    Description = "Remove all non-essential workspace parts (local only)",
    Aliases     = { "clearws" },
    Usage       = "clearworkspace confirm",
    Execute     = function(args)
        if args[1] ~= "confirm" then
            LumoAdmin.Notify({
                Title   = "ClearWorkspace",
                Message = "Run 'clearworkspace confirm' to proceed. This is destructive!",
                Type    = "Warning",
                Duration = 5,
            })
            return
        end
        local removed = 0
        for _, obj in ipairs(workspace:GetChildren()) do
            if obj:IsA("BasePart") and obj ~= workspace.Terrain then
                obj:Destroy()
                removed += 1
            end
        end
        LumoAdmin.Notify({
            Title   = "ClearWorkspace",
            Message = "Removed " .. removed .. " parts (client-side only).",
            Type    = "Success",
        })
    end,
})
Example D — Looping command with toggle
lualocal bhopConn  = nil
local bhopActive = false

LumoAdmin.AddCommand("bhop", {
    Description = "Toggle bunny hop (auto-jump on land)",
    Aliases     = { "bunnyhop" },
    Usage       = "bhop",
    Execute     = function()
        local lp  = game.Players.LocalPlayer
        local UIS = game:GetService("UserInputService")
        local RS  = game:GetService("RunService")

        if bhopActive then
            bhopActive = false
            if bhopConn then bhopConn:Disconnect() bhopConn = nil end
            LumoAdmin.Notify({ Title = "Bhop", Message = "Disabled.", Type = "Info" })
            return
        end

        bhopActive = true
        bhopConn   = RS.Heartbeat:Connect(function()
            local char = lp.Character
            local hum  = char and char:FindFirstChildOfClass("Humanoid")
            if hum and UIS:IsKeyDown(Enum.KeyCode.Space)
               and hum:GetState() == Enum.HumanoidStateType.Landed then
                hum:ChangeState(Enum.HumanoidStateType.Jumping)
            end
        end)
        LumoAdmin.Notify({ Title = "Bhop", Message = "Enabled. Hold Space to bhop.", Type = "Success" })
    end,
})

12. Hosting on GitHub & loadstring
Step 1 — Create your repository

Go to github.com → New repository
Name it (e.g. lumo-admin)
Set to Public (required for raw access without auth)
Upload LumoAdmin.lua to the root or a subfolder

Step 2 — Get the raw URL
Navigate to LumoAdmin.lua in GitHub, click Raw, and copy the URL.
It will look like:
https://raw.githubusercontent.com/YourUsername/lumo-admin/main/LumoAdmin.lua
Step 3 — Load in your executor
lualocal LumoAdmin = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/YourUsername/lumo-admin/main/LumoAdmin.lua"
))()
Step 4 — Adding commands in a separate file
Create an extensions/ folder in your repo and put custom command files there:
extensions/myCmds.lua
lua-- This file receives LumoAdmin as an argument
return function(LumoAdmin)
    LumoAdmin.AddCommand("myCustomCmd", {
        Description = "My personal command",
        Execute = function(args)
            LumoAdmin.Notify({ Title = "Custom!", Message = "It works!", Type = "Success" })
        end,
    })
    -- Add as many commands as you want here
end
Load both in your executor:
lualocal LumoAdmin = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/YourUsername/lumo-admin/main/LumoAdmin.lua"
))()

-- Load and apply extensions
local applyMyCmds = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/YourUsername/lumo-admin/main/extensions/myCmds.lua"
))()
applyMyCmds(LumoAdmin)
